# World News Digest

Ежедневный русскоязычный дайджест мировых новостей. GitHub Actions запускает Node.js/TypeScript-скрипт в 09:00 `Europe/Kyiv`; он читает RSS, выбирает публикации за предыдущую местную календарную дату, просит Gemini перевести и ранжировать их, а затем отправляет результат через Telegram Bot API.

## Что входит

- Источники RSS: BBC News, The Guardian, Al Jazeera, DW, NPR World и Le Monde International. Для Reuters и Associated Press сейчас нет надёжного бесплатного публичного RSS; прежние адреса были недействительными или шли через сторонний RSSHub proxy, поэтому они удалены. Если отдельная лента недоступна, остальные продолжают работать; если не удалось получить ни одной статьи, запуск завершается ошибкой.
- Раздел вчерашних новостей: только статьи с датой публикации за вчера в `Europe/Kyiv`, не более 10.
- Раздел событий на сегодня использует отдельный сборщик официальных расписаний, независимо от RSS-статей и даты публикации анонса. Сейчас подключены официальный Open Data API заседаний Европарламента, HTML-календарь заседаний ЕЦБ, официальный календарь сезона Formula 1 и официальный список мероприятий CES/CTA. Сборщик сохраняет дату, известное время и часовой пояс, описание, официальный URL, категорию и статус `confirmed`; отменённые записи отбрасываются, события с известным временем фильтруются по факту начала. Gemini получает только найденные записи и может выбрать до 10 по значимости; приложение не принимает от модели новые события, даты или ссылки.
- Ограничения охвата событий: календарь конференций ООН является официальной веб-страницей, но его машиночитаемый RSS/ICS/API не подтверждён и он не подключён. Календарь Eurostat предлагает iCalendar через интерактивную кнопку, но стабильный публичный URL календаря нельзя надёжно получить из доступной страницы без выполнения её клиентского JavaScript; он пока не включён в автоматический сбор. Публичный календарь F1 указывает дни уик-энда, но не всегда время сессий или часовой пояс трассы. CES показывает анонсированные будущие мероприятия. Источники покрывают только указанные организации и соревнования, а не все международные встречи, матчи, судебные заседания или презентации. При недоступности источника код сообщает об ошибке и не подменяет его новостными RSS.
- Дедупликация по URL, ссылки на исходники, русский перевод, HTML-экранирование, разбиение по границам заголовков/новостей до 3900 символов и повторные попытки при временных ошибках Telegram.
- Пустой дайджест не отправляется.

## Требования

- Репозиторий GitHub с включёнными GitHub Actions. Для стандартного GitHub-hosted runner выполнение в публичном репозитории бесплатно; у приватных репозиториев вычисления расходуют включённый лимит плана и сверх него могут тарифицироваться. Для нулевого риска оплаты используйте публичный репозиторий либо проверьте ограничения расходов GitHub до запуска. Исходный код станет публичным, GitHub Secrets останутся скрытыми. См. [GitHub Actions billing](https://docs.github.com/en/billing/concepts/product-billing/github-actions).
- API-ключ Gemini из Google AI Studio на бесплатном уровне. Квоты зависят от модели и проекта и могут меняться. До запуска проверьте лимиты в AI Studio и [тарифы Gemini](https://ai.google.dev/gemini-api/docs/pricing). Создайте ключ проекта без подключённого Cloud Billing и не добавляйте платёжный способ: при исчерпании квоты API должен завершиться ошибкой, без перехода на оплачиваемое использование. Приложение не выбирает платный тариф автоматически, однако само по себе не может определить, подключён ли billing к проекту ключа.
- Telegram-бот и ваш `chat_id`. Создание бота через BotFather и получение chat ID требуют действий в Telegram; токены храните только в Secrets.
- Бесплатный GitHub Actions для вашего репозитория в пределах актуального лимита минут GitHub. См. [GitHub Actions billing](https://docs.github.com/en/billing/concepts/product-billing/github-actions).

## Настройка локально

```bash
npm ci
```

В PowerShell скопируйте шаблон командой `Copy-Item .env.example .env`; в macOS/Linux — `cp .env.example .env`.

Заполните `.env` значениями (никогда не коммитьте его). Для локальной проверки установите `DRY_RUN=true`, затем запустите:

```bash
npm test
npm run build
npm start
```

Dry run выполняет RSS-запросы и вызов Gemini, печатает подготовленные сообщения, но не обращается к Telegram. Это всё ещё использует внешние сервисы и требует доступного бесплатного API-лимита. Тесты используют локальные данные и не требуют ключей или сети.

По умолчанию приложение работает в безопасном режиме и не отправляет сообщения, даже если `DRY_RUN` отсутствует или содержит любое значение, кроме точного `false`. Для реальной отправки требуется явно установить `DRY_RUN=false` и задать все три переменные. `npm start` в таком случае отправляет сообщения в указанный чат.

## GitHub Secrets

В Settings → Secrets and variables → Actions добавьте:

| Secret | Значение |
| --- | --- |
| `GEMINI_API_KEY` | API key из Google AI Studio |
| `TELEGRAM_BOT_TOKEN` | токен Telegram-бота |
| `TELEGRAM_CHAT_ID` | личный chat ID, группы или канала |

Workflow `.github/workflows/daily-digest.yml` запускает сборку и отправку по расписанию `0 9 * * *` в `Europe/Kyiv`; GitHub применяет часовой пояс IANA, включая правила сезонного перевода часов. Scheduled runs могут задерживаться при высокой нагрузке. Ручной запуск во вкладке Actions по умолчанию использует `dry_run=true`: он вызывает RSS/Gemini и выводит дайджест в лог, но не вызывает Telegram. Установите `dry_run=false`, только если хотите вручную отправить дайджест. Платёжные данные workflow не использует.

## Публикация и запуск в GitHub

1. Создайте пустой репозиторий на GitHub. Не добавляйте к нему автосоздаваемые README, `.gitignore` или лицензию: они уже есть здесь.
2. В PowerShell из папки проекта проверьте `git status`, затем добавьте файлы, создайте коммит и подключите созданный репозиторий:

   ```powershell
   git init
   git add .
   git commit -m "Create daily world news digest"
   git branch -M main
   git remote add origin https://github.com/<USER>/<REPOSITORY>.git
   git push -u origin main
   ```

3. На GitHub откройте **Settings → Secrets and variables → Actions → New repository secret** и добавьте три секрета из таблицы выше. Для `dry_run` вручную достаточно `GEMINI_API_KEY`; для плановой или ручной реальной отправки нужны все три.
4. Убедитесь, что GitHub Actions включён: **Actions → Enable workflows**, если GitHub запросит это.
5. Сначала проверьте workflow вручную: **Actions → Daily world news digest → Run workflow**, оставьте `dry_run=true`. Посмотрите лог выполнения и сформированный дайджест.
6. Для проверки доставки запустите вручную с `dry_run=false`; это отправит реальные сообщения в настроенный Telegram-чат.
7. После этого расписание запускается ежедневно в 09:00 по `Europe/Kyiv`. Персональный компьютер должен быть выключен или может не иметь установленного Node.js: Node 22 и зависимости устанавливаются на GitHub-hosted runner.

## Безопасность и ограничения

- API-ключи читаются только из переменных среды и GitHub Secrets.
- RSS/публикации и выбранные календари не дают гарантированно полного мирового охвата; порядок, полнота и доступность данных зависят от издателей и организаторов.
- Gemini может ошибаться в переводе и оценке значимости. Подборка событий ограничивается записями из подключённых официальных расписаний; проверяйте первоисточник по ссылке.
- Для бесплатного Gemini Google может использовать ввод/вывод для улучшения продуктов согласно условиям бесплатного уровня. Не добавляйте в RSS-подборку конфиденциальные материалы.
- При 429/ошибке квоты Gemini доставка не происходит. Telegram временные сетевые ошибки и 429 повторяются ограниченное число раз; окончательная ошибка помечает запуск GitHub Actions как failed. Тариф/лимиты провайдера не переключаются кодом.
- Необходимость читать RSS через сайт издателя зависит от его условий и технических ограничений. Используются только публичные RSS-ленты и сохраняются ссылки/названия изданий; код не скачивает платные полные тексты статей.
